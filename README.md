# homework-auto-plus（AI 实时读屏协作版）

与旧版 `homework-auto`（一键自动答题）不同，本工作区**由 AI 实时读取手机界面判断**，
同时提供**基于跟读词表的自动答题脚本**（拼写/单选/配对全自动），减少人工逐题判断。

## 核心洞察（用户发现的规律）

拼写训练之前会有一个**跟读训练**。跟读训练里出现的所有词语（包括顺序）
就是接下来拼写训练的答案顺序。

因此流程为：

1. 跟读阶段：用户按录音跟读 → 每读一个词 `watch.py` 记录该词（含中文翻译）
   → 用户点「继续」→ 重复，直到跟读结束
2. 拼写/单选/配对阶段：`solve_all.py` 自动识别题型并按词表答题

## 文件

| 文件 | 说明 |
|---|---|
| `phone.py` | 实时读屏工具：dump 界面文本/坐标、截图、点击、滑动、按键 |
| `watch.py` | 跟读训练记录器：实时捕捉「题号+单词+翻译」，去重写入词表 |
| `solve_spelling.py` | 拼写题自动答题（按题号查词表点字母） |
| `solve_all.py` | **统一自动答题**：自动识别拼写/单选/连线/消消乐并答题 |
| `words_record.json` | 跟读记录（题号+单词+翻译） = 拼写答案顺序表 |
| `test_extract.py` | 单词识别模拟测试（含 .../ / / 组合等） |
| `test_solve.py` | 拼写字母匹配模拟测试（大小写/特殊字符） |
| `test_all.py` | 全题型答题逻辑模拟测试 |
| `shots/` | 截图目录 |

## 使用

### 0. 图形界面（推荐）

```powershell
# 双击一键启动脚本即可（首次自动安装 ttkbootstrap）
D:\Users\fzizp\Desktop\homework-auto-plus\start_gui.bat
# 或手动
python D:\Users\fzizp\Desktop\homework-auto-plus\solve_gui.py
```

GUI 功能：
- **实时状态面板**：词库录入（中文/英文/跟读记录条数）、答题进度（第N题/百分比）、
  当前题目、当前行为（正在做什么）、下一步打算（接下来要做什么）
- **控制按钮**：📦 加载词库 / ▶ 开始 / ⏸ 暂停 / ▶ 继续 / ⏹ 停止 / 清空日志
- **随时强制暂停**；点「继续」后会重新查看当前手机界面，判断题型和下一步再继续
- **彩色日志面板**：错误红 / 成功绿 / 词库紫 / 提示蓝 / 警告黄
- **📝 跟读录入**（每天开始前先录词库）：
  - 输入**总词数** → 点「**开始录入**」→ 自动预建题号 1~N 的空记录
  - 手机进入跟读后逐题自动记录**单词+翻译**；**漏掉的题自动留空**，后续题号照常录入
  - 实时显示「已录入 X/N」；「停止录入」结束，可在「✏️ 编辑词库」查看/补录漏掉的题
- **📚 词库管理**（每天词库不同，需每日新建/切换）：
  - 下拉框**切换词库**（自动列出 `records/` 目录及根目录所有 `words_record*.json`）
  - **➕ 新建词库**：按日期自动命名（如 `words_record_20260807.json`），存到 `records/` 目录
  - **✏️ 编辑词库**：表格查看，**双击任意单元格直接编辑**（题号/单词/翻译），
    或选中行后在下方快捷编辑区修改；底部 **Add Row / Delete Row / Save / Close** 按钮增删保存
  - 词库文件互不影响，每天一份，随时切换回看

### 1. 跟读记录（协作模式）

```powershell
python watch.py
```
终端会实时提示「已记录第 N 题: word（翻译）」，看到提示后再点「继续」。

### 2. 自动答题（推荐）

```powershell
python solve_all.py            # 处理当前一题/一屏后停
python solve_all.py --loop     # 持续自动答题
```

自动识别题型：
- **拼写题**：读题号 → 词表取答案 → 点字母（自动滑动展开长单词按钮）→ 检查+继续
- **单选题**：读题面（中文或英文）+ A/B/C/D → 词库匹配 → 点选项 → 检查+继续
- **连线题/消消乐**：提取中英格子 → 词库释义评分配对 → 依次点击 → 检查+继续
- **跟读题**：跳过等待人工

词库来源：`homework-auto/wordlist_g1.csv` + `wordlist_gk.csv` + `words_record.json`（单词+翻译）。

### 3. 实时读屏

```powershell
python phone.py dump             # 打印界面文本 + 按钮坐标
python phone.py shot             # 截图
python phone.py tap 540 1200     # 点击
```

## 已知要点

- 「检查」与「继续」按钮在**同一位置** (540, 2193)，点完检查直接点同位置即下一题
- 拼写题每排最多 4 个按钮；超过 12 个按钮（如 determination、make a difference）
  需**滑动屏幕**露出，脚本已自动处理
- 特殊字符按钮也要点击：斜杠 `/`（even if/though）、连字符 `-`（push-up）、
  省略号 `...`（cut ... out、compare ... with/to）
- 大小写：答案大写优先点大写按钮，无大写按钮时忽略大小写兜底
